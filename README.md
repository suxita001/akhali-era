# ახალი ერა — საიტი

სუფთა HTML, CSS და JavaScript. სერვერი და PHP არ სჭირდება.

## ნახვა ახლავე (დემო რეჟიმი)

ორჯერ დააწკაპუნეთ `index.html`-ზე და საიტი Chrome-ში გაიხსნება.

- ადმინ პანელი: `admin.html`, პაროლი **demo**
- დემო რეჟიმში ყველაფერი (ჯავშნები, ტექსტები, ფოტოები) ინახება მხოლოდ თქვენს ბრაუზერში. სხვები ამას ვერ დაინახავენ.

## რეალური გაშვება (Firebase, უფასო)

ჯავშნები და ადმინში შეტანილი ცვლილებები რომ ყველასთვის მუშაობდეს, საჭიროა Firebase. ერთხელ გასაკეთებელია, ~15 წუთი.

1. **პროექტი:** https://console.firebase.google.com → *Add project* → სახელი მაგ. `akhali-era`.
2. **ვებ-აპი:** Project settings → *Your apps* → `</>` (Web) → დაარეგისტრირეთ. გამოჩნდება `firebaseConfig = { ... }`. დააკოპირეთ და ჩასვით ფაილში `assets/js/config.js`:
   ```js
   window.FIREBASE_CONFIG = { apiKey: "...", authDomain: "...", projectId: "...", appId: "..." };
   ```
3. **ბაზა:** Build → *Firestore Database* → *Create database* → აირჩიეთ რეგიონი (მაგ. `europe-west`) → *production mode*.
4. **შესვლის მეთოდები:** Build → *Authentication* → *Get started* → *Sign-in method*:
   - ჩართეთ **Email/Password** (ადმინისთვის და ელ-ფოსტის ბმულით დადასტურებისთვის)
   - ჩართეთ **Google** (მონაწილეების ერთი შეხებით დადასტურებისთვის) → მიუთითეთ თქვენი ელ-ფოსტა → *Save*
   - Users → *Add user* — ადმინის ელ-ფოსტა და პაროლი
   - Settings → *Authorized domains* — თუ საკუთარ დომენს მიაბამთ (მაგ. `akhaliera.ge`), აქ დაამატეთ
   - Templates → *Email address verification* — სურვილისამებრ შეცვალეთ წერილის ტექსტი ქართულად, ენა: *Georgian*
5. **დაცვის წესები:** გახსენით `firestore.rules`, `admin@example.com` შეცვალეთ მე-4 ნაბიჯში დამატებული ელ-ფოსტით (რამდენიმე ადმინი — მძიმით). მერე Firestore → *Rules* → ჩასვით ფაილის მთელი შიგთავსი → *Publish*.
6. **ატვირთვა ინტერნეტში (Firebase Hosting):** კომპიუტერზე, ამ საქაღალდეში:
   ```
   npm install -g firebase-tools
   firebase login
   firebase use --add        (აირჩიეთ თქვენი პროექტი)
   firebase deploy
   ```
   საიტი გაიხსნება მისამართზე `https://<პროექტი>.web.app`. საკუთარი დომენი (მაგ. `akhaliera.ge`) Hosting → *Add custom domain*-იდან ებმება.
7. გახსენით `/admin.html`, შედით ელ-ფოსტით და პაროლით. პირველ შესვლაზე საწყისი ტექსტები და ბანაკები ავტომატურად ჩაიწერება ბაზაში. **ეს აუცილებელია ჯავშნების მიღებამდე** — წესები ამოწმებს, რომ ბანაკი ბაზაში არსებობს და რეგისტრაცია ღიაა.

> Google-ით დადასტურება და ბმულები მუშაობს მხოლოდ ინტერნეტში ატვირთულ საიტზე (არა ფაილიდან გახსნისას). დემო რეჟიმში ეს ნაბიჯი სიმულირებულია.

ნებისმიერ სხვა ჰოსტინგზეც იმუშავებს (Netlify, Vercel, cPanel) — უბრალოდ ატვირთეთ ფაილები. Firebase-ის ნაბიჯები 1–5 მაინც საჭიროა.

## როგორ მუშაობს ჯავშანი
1. მონაწილე ავსებს ფორმას (ნომერი ავტომატურად ფორმდება +995 5XX XX XX XX-ად, ფორმა ინახება გვერდის განახლებისასაც).
2. ამოწმებს მონაცემებს და ადასტურებს ელ-ფოსტას: **Google-ით** (ერთი შეხება) ან **ბმულით**, რომელიც ფოსტაზე მოდის.
3. ჯავშანი მხოლოდ ამის შემდეგ იგზავნება. ერთ ელ-ფოსტაზე ერთ ბანაკზე მხოლოდ ერთი ჯავშანი შეიძლება — ამას თავად ბაზის წესები ამოწმებს.

ყველაფერი უფასოა (Firebase-ის უფასო Spark გეგმა): Google-ით შესვლა — ლიმიტის გარეშე, დადასტურების წერილი — დღეში 1000-მდე.
SMS-ით ნომრის დადასტურება Firebase-ში მხოლოდ ფასიან გეგმაზეა, ამიტომ ნომერს ადმინი ადასტურებს დარეკვით.

## ადმინ პანელი
- **ჯავშნები** — სტატუსები (ახალი, დადასტურებული, გადახდილი, გაუქმებული), შიდა შენიშვნა, ძებნა, დარეკვა ერთი შეხებით, Excel-ში ჩამოტვირთვა.
- **ბანაკები** — თარიღი, ფასი, ადგილი, ასაკი, აღწერა, ფასში რა შედის, პროგრამა, რეგისტრაციის გახსნა/დახურვა, მთავარ გვერდზე გამოჩენა, ახალი ბანაკი.
- **ტექსტები** — მთავარი გვერდი, ჩვენ შესახებ, კონტაქტები, სოციალური ქსელები, ზედა ზოლი.
- **კითხვები** და **გალერეა** (ფოტოები ავტომატურად მცირდება).

## გუნდი (რამდენიმე ადმინი)
მთავარი ადმინის ელ-ფოსტა წერია `firestore.rules`-ში (`isOwner`). მთავარი ადმინი ადმინ პანელის „გუნდი“ გვერდიდან ამატებს სხვა მენეჯერებს ელ-ფოსტით. ისინი შედიან **Google-ით**.

## ფაილები
- `index.html`, `camps.html`, `camp.html`, `about.html`, `gallery.html`, `faq.html`, `book.html` — საიტის გვერდები

- `assets/css/` — დიზაინი, `assets/js/` — ლოგიკა (`config.js` — Firebase-ის პარამეტრები)
